Privacy

Saith Developments · last updated 14 November 2026

This page covers the Saith Developments apps hub and StoreReport, the internal tool we use to read our own store and ad reports. Each app has its own privacy policy, linked from its page on the hub.

The apps hub website

The hub is a static page hosted on GitHub Pages. It has no accounts, no forms, no analytics and no ads. GitHub, as the host, may log basic request data such as IP addresses; see GitHub's privacy statement. The page loads fonts from Google Fonts.

StoreReport

StoreReport is used only by us, with our own Google and Apple developer accounts. When we sign it in with Google, it asks for read-only access to our AdMob reports (admob.readonly). It uses that access only to read our own apps' estimated ad earnings and impressions, so we can see each day's totals.

  • It does not read any other Google data, and it never changes anything in AdMob.
  • The report figures and the access token stay on our own devices. They are not sold, shared or used for advertising.
  • Access can be removed at any time from the Google account's third-party connections page.

StoreReport's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
